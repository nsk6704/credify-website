# UpWell Website

Official landing page for [UpWell](https://github.com/nsk6704/UpWell) - An Android app for tracking habits, finances, and well-being with gamification.

## Live Site

[Visit Website](https://upwell.sakethkashyap.dev) <!-- Update with your deployed URL -->

## About

This is the landing page for UpWell, showcasing:
- **Features**: Financial tracking, health & fitness, mindfulness tools
- **Gamification**: XP system, level progression, streaks
- **Tech Stack**: React Native, Expo, TypeScript, SQLite
- **Privacy**: 100% local storage, no cloud sync
- **Getting Started**: Installation guide, FAQs
- **iOS Waitlist**: Interest form for future iOS version


## Key Features

- **Responsive Design**: Mobile, tablet, and desktop optimized
- **Smooth Animations**: Intersection observers, fade-ins, hover effects
- **CDN-Based**: Google Fonts, Font Awesome icons
- **Fast Loading**: No build tools, minimal dependencies
- **SEO Friendly**: Semantic HTML, meta tags
