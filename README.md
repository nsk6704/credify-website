# Credify Landing Page

Professional landing page for the Credify app.

## Deployment Options

### GitHub Pages (Free)
1. Push the website folder to your repository
2. Go to Settings > Pages
3. Select branch and folder
4. Site will be live at `https://sakethkashyap.github.io/credify`

### Vercel (Free)
1. Import project from GitHub
2. Set root directory to `website`
3. Deploy
4. Custom domain support included

### Netlify (Free)
1. Drag and drop the website folder
2. Or connect to GitHub repository
3. Deploy
4. Custom domain support included

## Local Development

Simply open `index.html` in a browser to preview locally.

## Customization

- Update GitHub links in `index.html` (replace `sakethkashyap/credify` with your repo)
- Add app screenshots by replacing the placeholder in the hero section
- Modify colors in `styles.css` by changing CSS variables
- Update download links once you have GitHub releases

## Structure

- `index.html` - Main landing page
- `styles.css` - All styling and responsive design
- `script.js` - Smooth scrolling and animations
- `README.md` - This file
